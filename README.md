# TerraSpectra: Hyperspectral Crop Disease Forecasting System

TerraSpectra is an end-to-end pure-Python geospatial deep learning pipeline for early-stage agricultural crop stress and disease detection. It processes 3D hyperspectral data cubes (`64 × 64 × 16` PCA-reduced spectral bands), classifies pixel-level spatial-spectral patches using a PyTorch **3D Convolutional Neural Network (3D-CNN)**, serves predictions via a **FastAPI** REST backend, and visualizes affected farm acreage on an interactive **Streamlit + PyDeck + Plotly** GIS dashboard.
